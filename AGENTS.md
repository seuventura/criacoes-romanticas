# AGENTS.md

As instruções para qualquer IA ou agente que trabalhe neste projeto estão no **[CLAUDE.md](CLAUDE.md)**.
Leia-o inteiro antes de começar.

Resumo das regras obrigatórias:

1. `CLAUDE.md` descreve **somente o estado atual** do sistema.
2. `HISTORICO.md` guarda **mudanças, decisões e o que foi removido**.
3. **Ao terminar cada tarefa, atualize os dois:** uma entrada nova no topo do `HISTORICO.md` e o `CLAUDE.md`
   ajustado para refletir o estado atual.
